# ערכת הפקה: קומפוזיציה ב-HTML, רינדור ל-MP4

זו הדרך שבה נבנה ריל ההשקה של אלה (ריל 3). אין תוכנת עריכה: הסרטון הוא עמוד HTML שבו `seek(t)` מצייר את הפריים לזמן `t`, וסקריפט שמצלם פריים-פריים ומקודד.

| קובץ | מה |
|---|---|
| `index.html` | הקומפוזיציה. משנים את `BPM` ואת רשימת `CUTS` (טקסט, פונט, משקל, גודל, רקע, כמה פעימות). האורך נגזר מהשוטים |
| `render.cjs` | `node render.cjs index.html out.mp4 30` מרנדר ל-1080×1920, H.264, 30fps |

## דרישות
- Node עם `playwright` ו-Chromium (בסשני הענן של Claude זה מותקן).
- `ffmpeg`.
- רשת ל-Google Fonts בזמן הרינדור. בלי רשת הפונטים העבריים לא נטענים והסרטון יוצא בפונט ברירת מחדל. הסקריפט מחכה ל-`document.fonts.ready` לפני הפריים הראשון.

## כללים שלמדנו
- **כל פריים פונקציה של הזמן.** בלי `setTimeout`, בלי `transition`, בלי אנימציות CSS בזמן אמת: הרינדור קופץ בין פריימים, והן לא יתפסו.
- **חיתוכים על רשת הקצב.** `beats` לכל שוט, לא שניות. ככה שיר ב-BPM הזה מסתנכרן באינסטגרם.
- **בלי מוזיקה בקובץ.** את השיר בוחרים באינסטגרם.
- **נקודת הקצב** בפינה (`#beat`) נועדה לבדיקה בלבד. מוחקים אותה לפני הפקה.
- **תיקון טקסט** = שינוי שורה ב-`CUTS` ורינדור של דקה. 21 שניות ב-30fps הן 630 פריימים, בערך דקה.
